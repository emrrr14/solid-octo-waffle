# solid-octo-waffle

**The Punchline Press** — a one-page birthday card writer.

Open `index.html` in a browser. Give it a name, an age and a hobby and it
writes the inside of the card for you: a festive title that recolours every
90–100 ms, and each card rendered as an open card spread (confetti and the
age on the left leaf, handwriting on ruled paper on the right). New cards
print on top; older ones stay stacked underneath.

Every card can be reworded, copied or binned. No build step, no
dependencies beyond the Google Fonts stylesheet.
